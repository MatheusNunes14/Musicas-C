# App de Músicas em C

Sistema de cadastro de músicas desenvolvido em linguagem C

Funcionalidades:Cadastrar músicas, Listar músicas, Buscar música por ID, Atualizar música, Remover música

Estrutura:

O trabalho utiliza:Struct personalizada, Vetor de structs, Menu interativo, Estruturas de repetição, Estruturas de decisão, CRUD completo, Dados armazenados

Cada música possui: ID, Nome, Artista e Duração

Como executar:

Compile o programa:

gcc cadastro.c -o app 

./app
